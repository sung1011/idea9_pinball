# idea9_pinball

惯性滑动弹球。本机一局：1 人控红方钩刺 vs 1～2 个蓝方简 bot（默认 2）。

线上预览：https://sung1011.github.io/idea9_pinball/

仓库 **Settings → Pages** 的 Source 需选 **GitHub Actions**（首次可能要手动点一次）。推送到 `main` 后由 Actions 自动构建并发布。

## 本地运行

```bash
npm i
npm run dev
```

浏览器打开终端提示的本地地址（开发服务在 `/idea9_pinball/` 路径下），可见俯视场地（圆角矩形、中点圈半径 2.5、左右矮柱、红/蓝半场出生点）。

## 一局

- 开局 Countdown 3s，随后开战 2s 无敌。局长 240s；先到 100 分立即结束；到点比总分。
- 平分进入 30s 加时，只计中点分；再平则下一次击破方胜。
- 击破：HP≤0 离场，击杀队伍 +15；击杀前 3s 内对死者造成过碰撞伤的队友（非击杀者）最近 1 人 +5。本机红方无队友，助攻逻辑已单测覆盖。
- 回场：HP≤0 立即离场，5s 后于己方半场出生点出现，回场 2s 无敌（可滑、可放技能；碰撞不伤自己也不造成撞伤）。0 血即使当帧无 hit 也会进回场，不会停在场上。
- 中点：每秒结算；区内活人数严格更多一方 +2/秒；相等 0；离场当帧不占人。
- HUD：双方分、倒计时、中点归属、回场倒计时、击破提示。

操作（控红球，**点地纠偏、无左摇杆**）：
- 瞄准：鼠标世界坐标 / 触屏最后触点持续设 `targetDir = normalize(pointer − ball)`。金矛尖指示目标方向。Aim 只拧速度方向，不加油门。
- 保底巡航 2.5 格/秒，上限 8。全程弱拧 45°/s；撞墙/柱/球后 0.3s 强拧 120°/s（替换原约 90°/s 微调）。
- 技能 1–4：仅 `1`勾过来 / `2`方向捅×3 / `3`推过去 / `4`急停蓄弹 或右侧四键（不绑 `Q`/`W`/`E`）。按下进瞄（可无限持有），**释放后才走前摇**；再按同键或左键/点地释放。点在技能键上不抢 Aim。
  - 勾过来 CD8：释放后 0.4s；扇 50° 距 6；墙挡；中则己速 10 飞向目标 + 伤 8 + 抵达开撞窗；未中 CD 变 4s；不勾友军
  - 方向捅×3 CD6：释放后 0.25s；扇 40° 距 2.2；0.15s 间隔伤 9/9/14；每次自推 0.4；第三下 0.25s 硬直；挥空仍进 CD
  - 推过去 CD10：释放后 0.35s；冲刺 4.5 格约 0.35s；碰敌沿冲刺向初速 12 + 伤 12 + 己 0.25s 撞窗；己留 70% 剩余速；撞墙提前结束
  - 急停蓄弹 CD12：即放；0.6s 摩擦×10（期间不拉保底）；结束按朝向 11 速弹出 + 0.25s 撞窗
- 取消：右键 / Esc / 瞄准中的取消键。取消不生效。触屏点地只纠偏。
- `R` 只重开一局，不绑 Skill4。

蓝方简 bot：共用保底冲靠近 + 急停 + 偶发勾过来，不打捅×3 连招；可被撞死并回场。

调试键（`Z`/`X`/`C`/`V` 双方均在场才生效，不重置一局）：
- `Z`：背后对撞测试（后乘区 ×1.35）
- `X`：侧面撞击测试（侧 ×0.7）
- `C`：正面/对撞测试（前 ×1.0）
- `V`：轻蹭测试（不掉血只改向）
- `R`：重开一局
- `F` 红 +10 分、`G` 蓝 +10 分、`T` 跳过 30s、`Y` 当前阶段剩 1s

球带惯性、摩擦后回到保底 2.5，撞墙/矮柱反弹，速度上限 8。

碰撞：相对速度 ≥ 4（主动撞窗内阈值 2.5）才掉血，否则轻蹭只改方向。伤害 = 6 × (相对速度 − 阈值) × 受击朝向系数（前 1.0 / 侧 0.7 / 后 1.35），单次上限 28；仅掉血时沿法线轻弹。无敌或同队碰撞不掉血。
