# idea9_pinball

惯性滑动弹球 3v3。

线上预览：https://sung1011.github.io/idea9_pinball/

仓库 **Settings → Pages** 的 Source 需选 **GitHub Actions**（首次可能要手动点一次）。推送到 `main` 后由 Actions 自动构建并发布。

## 本地运行

```bash
npm i
npm run dev
```

浏览器打开终端提示的本地地址（开发服务在 `/idea9_pinball/` 路径下），可见俯视场地（圆角矩形、中点圈、左右矮柱、两颗占位球）。

操作（控红球，无移动键）：
- 瞄准：鼠标相对红球；手机横屏用左虚拟摇杆。瞄准无超时，直到释放或取消。
- 技能 1–4：`1`/`2`/`3`/`4`（兼 `QWE`）或右侧虚拟四键。按下进瞄，再按同键或左键释放 stub（朝向刷新 + Δv≈3 + 0.25s 主动撞窗，短 CD 0.4s）。
- 取消：右键 / Esc / 触屏点空白。取消不冲量。
- 微调：任意碰撞（含轻蹭）后 0.3s 内，Aim 把速度方向轻扭约 90°/s；HUD 亮微调提示。
- `R` 仍为调试重置（Skill4 用 `4`）。

调试：`C` 正面对撞、`Z` 背后撞、`X` 侧面撞、`V` 轻蹭、`R` 重置位置与血量。球带惯性、摩擦（满速约 2 秒滑到爬行）、撞墙/矮柱反弹，速度上限 8。

碰撞：相对速度 ≥ 4（主动撞窗内阈值 2.5）才掉血，否则轻蹭只改方向。伤害 = 6 × (相对速度 − 阈值) × 受击朝向系数（前 1.0 / 侧 0.7 / 后 1.35），单次上限 28；仅掉血时沿法线轻弹。左上角 HP HUD 显示双方血量、瞄准/微调状态与最近一击。
