# idea9_pinball

骑士冲杀。本机固定 2v2：玩家控红1 + 简 bot 红2 vs 2 蓝简 bot。开局和每次 `R`：队友与两名敌方从含镜卫的全英雄池均匀随机（同局可重复）；玩家用上次所选英雄作缺省（`ks.lastHeroId`），无记录时默认钩刺。设置常规页「玩法」可切「八杀 / 占点」（`ks.lastModeId`，无记录默认八杀）；换玩法立刻重开倒计时。八杀先到 8 杀（加时先超前 1 杀，再平比剩余血），无中圈/左右矮柱，有药水（正式开战第10秒首瓶，之后每45秒），无随机环境伤害圈；占点仍是击破分+领地分先到 100。物理仍是圆体惯性滑动（碰撞半径 1.0 格）；外观为全部英雄共用 A 骑装透明人马（蓝方原图，红方仅盔甲+盾牌局部换红，白马/长枪不染，枪尖对齐 2.24；分层已加载时七层四蹄步态由速度驱动，低速收步，侧滑/后滑马头仍跟瞄准；编号/血条保留；缺分层回退整图，缺图回退圆盾羽冠金矛；冲锋残影仍为队色圆影）。本地玩家脚下仅一层奶黄色身份圈+深棕细描边（约盾径 1.3 倍），只本人有，其他单位无该类常驻圈，不进残影、无头顶「我」牌。磁环对外辉环 / 斥波 / 壁行 / 囚环。链生对外愈链 / 盾脉 / 援勾 / 扰锋。钉壳对外甲垒 / 刺盾 / 顶冲 / 钉锚。闪弧对外侧闪 / 掠刃 / 回印 / 虚影。井绳对外索爆 / 易位 / 索桩 / 回索。镜卫对外折光 / 反照 / 裂镜 / 镜壁。设置常规页「我的英雄」可换自己（只换 kit，不换号）并立刻记住下次缺省；不能换队友，队友仍开局/重开随机。GM `H` 只循环红1 已解锁英雄。战场高 20、宽 20×956/440（iPhone 18 Pro Max 横屏比例）：红蓝各上下两出生；占点领地中心半径 2.5。永远横屏对局：进入/刷新后等第一次稳定横屏（宽≥高）再按真正可见区 cover 适配一次并锁定战场显示比例（独立窗再等窗稳定，避免 100dvh 大于可见区；竖窗不按竖屏比例锁死；横屏后缩窗裁切、扩窗留既有背景，不随窗口再缩放）；系统锁当前横屏侧（已在 primary/secondary 则锁这一侧，否则 `landscape-primary`），不允许 180° 对调，也不对 `#app` 做 90° CSS 旋转；无转屏提示。HUD 叠四角（顶中比分或击杀胶囊，顶右 科 + ? + 齿轮，右下 Skill1–4 约 60px 显示该英雄圆形剪影技能图标（v1，无木环），缺图用短名，其左为第五键必杀+能量环：钩刺为无畏冲锋，磁环为沉磁井，链生为均血，其余点按/`5` 显示 todo；瞄准中取消键锚在当前技能正上方；技能键上方本局统计无行首图标、无「我」标记，名称与数值按队色）。钩刺满能量确认后先沿枪尖反向退三步（每步 0.4s / 0.8 格），再沿活枪尖加速穿刺，碰敌不回头，与盾冲/蓄势不是同一套。冲出初速/加速度/上限/转向/伤害/能量不变。触屏左下常显半透明圆形瞄准摇杆（约 104px，避开安全区）：拖动输出相对底座的单位朝向给枪尖/技能，约 12% 死区、外圈钳制，松手回中不放技能；纯鼠标桌面不常显，仍用鼠标瞄准。不是自由移动或推力。

线上预览：https://sung1011.github.io/idea9_pinball/

仓库 **Settings → Pages** 的 Source 需选 **GitHub Actions**（首次可能要手动点一次）。推送到 `main` 后由 Actions 自动构建并发布。

## 本地运行

```bash
npm i
npm run dev
```

浏览器打开终端提示的本地地址（开发服务在 `/idea9_pinball/` 路径下），可见俯视宽屏场地铺满视口（高 20、宽 20×956/440，圆角矩形、领地纹章圈半径 2.5、左右半场矮柱、红/蓝半场底线木栏，开局四人在上下出生）。默认战场无 FPS / 网格 / 碰撞日志等调试层。右上角齿轮开设置（常规 / 版本 / GM，点空白关）；齿轮左侧 `?` 与常规页「怎么玩」打开同一份说明卡。新版只靠轮询 `public/versions.json` 检测，确认后本机不再弹；设置 → 版本展示最近约 10 条。发版请往该文件追加条目，不打 git tag。

## 一局

- 开局 Stall：红左半场上下、蓝右半场上下各一出生；红左底 / 蓝右底描边围栏（开口朝领地），大号倒计时 5s，栏内不可出。结束围栏消失，冲锋 1s（朝领地；前约 0.2s 拉到峰值 7.5，上限仍 8；禁技能、几乎锁拧、全程无敌，并入原开局无敌）。随后才点地纠偏、放技能。Esc 或点空白可跳过 Stall，直接开战并清栏。局长 240s；先到 100 分立即结束；到点比总分。
- 平分进入 30s 加时，只计领地分；再平则下一次击破方胜。
- 击破：HP≤0 离场，击杀队伍 +15；击杀前 3s 内对死者造成过碰撞伤的队友（非击杀者）最近 1 人 +5。红2 击破给分，助攻认红1/红2。
- 回场：HP≤0 立即离场，5s 后于己方半场出生点出现，回场 2s 无敌（可滑、可放技能；碰撞不伤自己也不造成撞伤）。0 血即使当帧无 hit 也会进回场，不会停在场上。自己离场时屏幕中央偏上显示「复活还需 X 秒」（仅本人、无遮罩、战况可见）；队友/敌人离场仍用短 toast。
- 领地：每秒结算；区内活人数严格更多一方 +2/秒；相等 0；离场当帧不占人。
- HUD：顶中一颗胶囊（红分 | 计时 | 蓝分，带小队标）、顶右 `科` + `?` + 小齿轮（`科` 在 `?` 左，`?` 在齿轮左）贴窗顶。玩法在设置常规页「玩法」选择（八杀 / 占点），左上不再放入口。自己的英雄在设置常规页「我的英雄」选择（未解锁禁用）。Skill1–4 一行横排贴视窗右下（圆钮约 60px；瞄准中「取消」出现在当前技能正上方）。局内 chrome 为羊皮纸 + 2px 木框（中古骑士团、偏卡通 Q 版）；金只点在中间计时，技能就绪不闪金。玩法说明卡与设置三页（常规 / 版本 / GM）同族：羊皮纸底、2px 木框、墨色标题，关闭钮无金闪。胜利结算板同族羊皮纸+2px木框，可用金矛碎裂火花作庆祝点缀（局内金仍只点计时）。不再单独放左上 / 右上比分胶囊。击破 / 回场只出短 toast。换英雄只换技能组，血量 / 位置 / 速度 / 队伍 / 编号 / 对局不变，进行中的瞄准或前摇会取消。血量画在骑士头顶。掉血 / 回血在单位旁冒仅数字飘字（伤红橙 / 愈绿；护盾青通道有数值才出），不挡技能键与顶中胶囊。长按技能键约 0.4 秒弹出骑士对外名 + 一行效果（CD 中也可看），松开收起；短按仍进瞄 / 同键释放。局结束弹出结算：胜/负、击破分与领地分、用时、科技点奖励与余额；「再来一局」等同 `R`。
- 科技（本机 `ks.techSave`）：新档 0 点、钩刺免费；其他现有英雄用科技点解锁（前三次付费各 30，之后各 60，自由选未解锁英雄，钩刺不计入次数）。钩刺四普通技能各一个永久槽位，可同时点亮：钩矛 30 / 连刺流血 30 / 盾冲 50 / 蓄势 50（弹出接触携带友军，只加条件强化，不改基础值）。其他现有英雄同样按「英雄→普通四技能→科技槽」展示，名称/图标/顺序读现有技能，一律 todo 不可购买，必杀不入科技。战外（倒计时/结算）购买，局内只读，进场快照生效。无装备栏、无玩法门槛。正常完成的人机/对战结算发点（占点胜 20 负/平 10；八杀第一或并列第一 20、其余 10）；练习 / 主动重开 / 切玩法重开不发；每场一次。练习入口在设置常规页，可试用全部英雄，不解锁不发点。进度只存在本机，清浏览器数据会丢。无真实联网/账号/付费；当前仍是本机 2v2 对 bot。

操作（控红方骑士，**点地纠偏、无左摇杆**）：
- 瞄准：鼠标世界坐标 / 触屏最后触点持续设 `targetDir = normalize(pointer − ball)`。金矛尖指示目标方向。Aim 只拧速度方向，不加油门。
- 保底巡航 2.5 格/秒，上限 8。全程弱拧 45°/s；撞墙/柱/球后 0.3s 强拧 120°/s（替换原约 90°/s 微调）；撞后不再画青色提示圈。
- 技能 1–4（钩刺对内 id 不变；对外显示）：仅 `1`钩矛 / `2`连刺×3 / `3`盾冲 / `4`蓄势 或左下四键（不绑 `Q`/`W`/`E`）。按下进瞄（可无限持有），**释放后才走前摇**；再按同键或左键释放。触屏瞄准中点空白（非技能键 / ? / 齿轮 / 取消键 / 设置里的选择）先把 aim 对准触点再释放，滑动只改朝向、抬手不释放。点在技能键上不抢 Aim。长按技能键约 0.4 秒可看对外名和一行效果，松开收起。
  - 钩矛（勾过来）CD8：释放后 0.4s；扇 50° 距 6；二次确认时按瞄准预览扇形/距离锁敌（与预览同一朝向），前摇结束对锁定目标出勾；墙挡勾索；中则己速 10 飞向目标 + 伤 8 + 抵达开撞窗；未中 CD 变 4s；不勾友军
  - 连刺（方向捅×3）CD6：释放后 0.25s；扇 40° 距 2.2；0.15s 间隔伤 9/9/14；每次自推 0.4；第三下 0.25s 硬直；挥空仍进 CD
  - 盾冲（推过去）CD10：释放后 0.35s；冲刺 4.5 格约 0.35s；碰敌沿冲刺向初速 12 + 伤 12 + 己 0.25s 撞窗；己留 70% 剩余速；撞墙提前结束
  - 蓄势（急停蓄弹）CD12：即放；2.6s 摩擦×10（期间不拉保底）；结束按弹出瞬间可见枪尖方向 16.5 速弹出（约原 1.5 倍）+ 0.25s 撞窗（蓄势中转向改枪尖即改弹出）。点亮蓄势科技后，该 0.25s 窗内沿途接触的存活友军可被携带冲锋，不加额外伤害
- 取消：右键 / Esc / 瞄准中的取消键（锚在当前技能键正上方）。取消不生效。触屏未进瞄时点地只纠偏。
- 磁环（左上下拉或 GM `H` 换成红方，或打蓝1）：`1`辉环 / `2`斥波 / `3`壁行 / `4`囚环
  - 辉环（磁场）CD11：即放；身周半径 2 留 5s，敌每秒 6，己免
  - 斥波（推波）CD9：即放；锥 70° 射程 4，击退初速约 9，伤 8
  - 壁行（粘壁）CD14：即放；4s 撞墙不反弹沿壁滑，结束按朝向 8 速弹出（位移技）
  - 囚环（困圈）CD12：释放后 0.35s；自身为心或点地（距己≤4），半径 2.5 持续 3.8s；圈内敌物理关死出不去（夹在边缘），仍禁位移技，强放进 2s 短 CD；无 DoT；友军不受困；圈外可滑进
  - 沉磁井（第五键必杀，暂名）：满能量前方选点，圆心最远 6 格，确认后固定落点立即强吸 3 秒再爆炸；半径 4 格；圈内敌我含本人同等吸力；爆炸 20+10×圈内存活人数，只打敌人、完整不分摊；瞄准取消不耗能
- 链生（左上下拉或 GM `H` 换成红方）：`1`愈链 / `2`盾脉 / `3`援勾 / `4`扰锋
  - 愈链（治疗链）CD10：释放后 0.3s；扇 40° 距 6；扇内最近友 HOT / 敌 DoT，每秒 6 共 4s；无目标进 2s 短 CD
  - 盾脉（护盾脉冲）CD12：即放；距≤5 最近敌；与该敌短距贴附吸血 3s，每秒己 +8 敌 -8；无敌人进 2s 短 CD
  - 援勾（勾友）CD8：即放；距≤8 最近友或敌；对友拉自己向友，或残血友(<40%)轻拉向己 2 格；对敌击退初速约 10；不算对敌主动撞（位移技）；无目标进 2s 短 CD
  - 扰锋（范围沉默）CD15：释放后 0.2s；身周半径 5；圈内敌沉默 3s 不能放技能（可滑/可撞）；打断短瞄准；友军不受影响
  - 均血（第五键必杀，描述名）：满能量按下进瞄再确认，以自身为圆心半径 4 格立刻按生命百分比算术平均调血（敌我含本人，压线包括），圈内我方含本人再回最大生命 10% 不超满；无敌不参与；降血不走护盾/普通伤害/反伤，也不回充必杀能量
- 钉壳（左上下拉或 GM `H` 换成红方）：`1`甲垒 / `2`刺盾 / `3`顶冲 / `4`钉锚
  - 甲垒（叠甲）CD10：即放；3.5s 碰撞伤×0.4；未破甲结束回 8
  - 刺盾（反击刺）CD9：被动被主动撞后 2.5s 反 12 + 小推；主动开则 3s 内首次被撞反 16
  - 顶冲（短冲顶）CD8：即放；冲 3 格，命中主动撞+10（位移技）
  - 钉锚（定锚）CD13：释放后 0.3s；扇 45° 距 5；目标速度归零 0.6s，不能改朝向/放技能，仍可被推，位移≥1 断钉；上钉 6；钉中友军主动撞额外 10
- 闪弧（左上下拉或 GM `H` 换成红方）：`1`侧闪 / `2`掠刃 / `3`回印 / `4`虚影
  - 侧闪（侧移闪）CD7：释放后 0.15s；瞄准扇 40° 距 6 瞬移到最近敌背后（贴背短距、朝向对敌，位移技）；无目标进 2s 短 CD
  - 掠刃（擦伤刃）CD9：即放；给自己刀刃荼毒 8s；下次枪尖成功掉血 +6 后清除
  - 回印（标记回响）CD11：释放后 0.25s；距≤5 上标记 6s；下一次主动撞额外 14
  - 虚影（虚晃）CD14：即放；2.4s 无碰撞（位移技）；结束速度≥6 则开 0.2s 主动撞窗；困圈内不可用
- 井绳（左上下拉或 GM `H` 换成红方）：`1`索爆 / `2`易位 / `3`索桩 / `4`回索
  - 索爆 CD11：释放后 0.2s；身周半径 2.2 连炸 4 次、间隔 0.35s、每次伤 8，只打敌人；有桩则桩同步炸，4 次后收桩（非位移）
  - 易位（换位）CD16：释放后 0.45s；锁敌≤5；交换位置与瞬时速度 50%；伤 5（位移技）
  - 索桩（弹索桩）CD12：释放后 0.3s；投桩≤6 存在 7s；撞桩按壁反弹；己方撞桩开 0.25s 撞窗；同时仅 1 桩
  - 回索（收索）CD9：需有桩；桩与己连线宽 1，线上敌伤 6 并定身 2s（速度归零、不能自行离开/放技能，仍可碰撞；超出硬控 0.6s 上限）
- 镜卫（左上下拉或 GM `H` 换成红方）：`1`折光 / `2`反照 / `3`裂镜 / `4`镜壁
  - 折光 CD9：即放；1.5s 受伤 ×0.5，减免差额记入反照账本（只记自己实际减免，不与盾/甲双算）
  - 反照 CD8：消耗账本，扇形打首个敌人，伤害=账本量、封顶 60；空账或无目标不进 CD；打出的伤害不再入账
  - 裂镜 CD10：即放；自伤 24（红橙飘字）入账，周围溅 12 不入账；自伤走同一套击破/回场
  - 镜壁 CD14：即放；身前短墙 2.5s，敌方撞墙反弹，己方撞墙开 0.25s 主动撞窗
- `R` 只重开一局，不绑 Skill4；设置 → 常规也可重开。正式可用。

简 bot（红2 与两蓝同一套）：开局 / `R` 从含镜卫全池随机 kit（可重复），按当前英雄施放（钩刺：保底冲靠近 + 蓄势 + 偶发钩矛；磁环：推波 / 困圈 / 磁场 / 近壁粘壁；链生：扰锋 / 愈链 / 援勾；其余各用自己的四技能简策略）。可被撞死并回场。左上「队友」下拉可换红2 英雄，只换 kit，编号仍是 2，不写入玩家缺省。

调试（设置 → GM，默认开；关则下列键无效，`R` 仍可用。`Z`/`X`/`C`/`V` 双方均在场才生效，不重置一局）：
- `Z`：背刺测试（枪尖从背后戳中，伤害不再更高）
- `X`：侧身圆蹭测试（无枪尖命中，不掉血只弹开）
- `C`：枪尖对戳测试（双方互伤）
- `V`：同向轻蹭测试（相对速度≈0，伤≤0 不当命中，只改向）
- `R`：重开一局
- `F` 红 +10 分、`G` 蓝 +10 分、`T` 跳过 30s、`Y` 当前阶段剩 1s、`H` 只循环红1 已解锁英雄（设置「我的英雄」选中值跟着变；练习可循环全池）
- GM 页也可点按钮：碰撞测 / ±分 / 跳时 / 立即回场 / 换英雄

骑士带惯性、摩擦后回到保底 2.5，撞墙/矮柱反弹，速度上限 8。碰撞仍按圆。

碰撞：只有攻击方枪尖碰到受击方身体才掉血（单向，双方同时戳中可互伤）；身子圆碰圆只做物理分离。伤害 = 6 × 相对速度标量，单次上限 28，不再乘朝向、无相对速度门槛；伤≤0 不当命中。成功掉血后枪尖普攻进 1.5s CD，CD 中再戳不掉血、不刷新 CD。技能直伤 / 擦伤刃等独立结算，不受此 CD 限制。仅掉血时沿法线轻弹。无敌或同队碰撞不掉血。
