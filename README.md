# idea9_pinball

惯性滑动弹球。本机一局：1 人控红球 vs 1～2 个蓝方简 bot（默认 2）。

线上预览：https://sung1011.github.io/idea9_pinball/

仓库 **Settings → Pages** 的 Source 需选 **GitHub Actions**（首次可能要手动点一次）。推送到 `main` 后由 Actions 自动构建并发布。

## 本地运行

```bash
npm i
npm run dev
```

浏览器打开终端提示的本地地址（开发服务在 `/idea9_pinball/` 路径下），可见俯视场地（圆角矩形、中点圈半径 2.5、左右矮柱、红/蓝半场出生点）。

## 一局

- 开局 Countdown 3s，随后开战 2s 无敌。局长 240s；先到 100 分立即结束；到点比总分。
- 平分进入 30s 加时，只计中点分；再平则下一次击破方胜。
- 击破：HP≤0 离场，击杀队伍 +15；击杀前 3s 内对死者造成过碰撞伤的队友（非击杀者）最近 1 人 +5。本机红方无队友，助攻逻辑已单测覆盖。
- 回场：8s 后于己方半场出生点出现，回场 2s 无敌（可滑、可放 stub；碰撞不伤自己也不造成撞伤）。
- 中点：每秒结算；区内活人数严格更多一方 +2/秒；相等 0；离场当帧不占人。
- HUD：双方分、倒计时、中点归属、回场倒计时、击破提示。

操作（控红球，无移动键）：
- 瞄准：鼠标相对红球；手机横屏用左虚拟摇杆。瞄准无超时，直到释放或取消。
- 技能 1–4：`1`/`2`/`3`/`4`（兼 `QWE`）或右侧虚拟四键。按下进瞄，再按同键或左键释放 stub（朝向刷新 + Δv≈3 + 0.25s 主动撞窗，短 CD 0.4s）。
- 取消：右键 / Esc / 触屏点空白。取消不冲量。
- 微调：任意碰撞（含轻蹭）后 0.3s 内，Aim 把速度方向轻扭约 90°/s；HUD 亮微调提示。
- `R` 重开一局（Skill4 用 `4`）。

蓝方简 bot：无复杂寻路，周期朝中点或最近敌人给 stub 冲量，可被撞死并回场。

调试：`C` 正面对撞、`Z` 背后撞、`X` 侧面撞、`V` 轻蹭（双方均在场才生效，不重置一局）。`F` 红 +10 分、`G` 蓝 +10 分、`T` 跳过 30s、`Y` 当前阶段剩 1s。球带惯性、摩擦（满速约 2 秒滑到爬行）、撞墙/矮柱反弹，速度上限 8。

碰撞：相对速度 ≥ 4（主动撞窗内阈值 2.5）才掉血，否则轻蹭只改方向。伤害 = 6 × (相对速度 − 阈值) × 受击朝向系数（前 1.0 / 侧 0.7 / 后 1.35），单次上限 28；仅掉血时沿法线轻弹。无敌或同队碰撞不掉血。
