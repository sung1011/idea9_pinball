# idea9_pinball

骑士冲杀。本机一局：1 人控红方钩刺 vs 1～2 个蓝方简 bot（默认 2；蓝1 磁环）。物理仍是圆体惯性滑动；外观为程序几何骑士（圆盾、羽冠、金矛尖）。磁环对外辉环 / 斥波 / 壁行 / 囚环。链生对外愈链 / 盾脉 / 援勾 / 扰锋。钉壳对外甲垒 / 刺盾 / 顶冲 / 钉锚。闪弧对外侧闪 / 掠刃 / 回印 / 虚影。井绳对外双索 / 易位 / 索桩 / 回索。左下角可随时换红方英雄（只换 kit）；GM `H` 仍循环钩刺 → 磁环 → 链生 → 钉壳 → 闪弧 → 井绳。战场以横屏为主：竖持手机会出转横提示；PC 窄窗保持横构图并上下留黑边。

线上预览：https://sung1011.github.io/idea9_pinball/

仓库 **Settings → Pages** 的 Source 需选 **GitHub Actions**（首次可能要手动点一次）。推送到 `main` 后由 Actions 自动构建并发布。

## 本地运行

```bash
npm i
npm run dev
```

浏览器打开终端提示的本地地址（开发服务在 `/idea9_pinball/` 路径下），可见俯视场地铺满视口（圆角矩形、领地纹章圈半径 2.5、左右矮柱、红/蓝半场底线木栏）。默认战场无 FPS / 网格 / 碰撞日志等调试层。右上角齿轮开设置（常规 / 版本 / GM，点空白关）；常规页可开「怎么玩」。

## 一局

- 开局 Stall：红左底 / 蓝右底描边围栏（开口朝领地），大号倒计时 5s，栏内不可出。结束围栏消失，冲锋 2s（朝领地；前约 0.4s 拉到峰值 7.5，上限仍 8；禁技能、几乎锁拧、全程无敌，并入原开局无敌）。随后才点地纠偏、放技能。Esc 或点空白可跳过 Stall，直接开战并清栏。局长 240s；先到 100 分立即结束；到点比总分。
- 平分进入 30s 加时，只计领地分；再平则下一次击破方胜。
- 击破：HP≤0 离场，击杀队伍 +15；击杀前 3s 内对死者造成过碰撞伤的队友（非击杀者）最近 1 人 +5。本机红方无队友，助攻逻辑已单测覆盖。
- 回场：HP≤0 立即离场，5s 后于己方半场出生点出现，回场 2s 无敌（可滑、可放技能；碰撞不伤自己也不造成撞伤）。0 血即使当帧无 hit 也会进回场，不会停在场上。
- 领地：每秒结算；区内活人数严格更多一方 +2/秒；相等 0；离场当帧不占人。
- HUD（Layout B）：左上红分胶囊、右上蓝分胶囊、顶中计时胶囊、右下 2×2 技能、左下英雄下拉、右上小齿轮。击破 / 回场只出短 toast。换英雄只换技能组，血量 / 位置 / 速度 / 对局不变，进行中的瞄准或前摇会取消。血量画在骑士头顶。长按技能键约 0.4 秒弹出骑士对外名 + 一行效果（CD 中也可看），松开收起；短按仍进瞄 / 同键释放。局结束弹出结算：胜/负、击破分与领地分、用时；「再来一局」等同 `R`。

操作（控红方骑士，**点地纠偏、无左摇杆**）：
- 瞄准：鼠标世界坐标 / 触屏最后触点持续设 `targetDir = normalize(pointer − ball)`。金矛尖指示目标方向。Aim 只拧速度方向，不加油门。
- 保底巡航 2.5 格/秒，上限 8。全程弱拧 45°/s；撞墙/柱/球后 0.3s 强拧 120°/s（替换原约 90°/s 微调）。
- 技能 1–4（钩刺对内 id 不变；对外显示）：仅 `1`钩矛 / `2`连刺×3 / `3`盾冲 / `4`蓄势 或右侧四键（不绑 `Q`/`W`/`E`）。按下进瞄（可无限持有），**释放后才走前摇**；再按同键或左键/点地释放。点在技能键上不抢 Aim。长按技能键约 0.4 秒可看对外名和一行效果，松开收起。
  - 钩矛（勾过来）CD8：释放后 0.4s；扇 50° 距 6；墙挡；中则己速 10 飞向目标 + 伤 8 + 抵达开撞窗；未中 CD 变 4s；不勾友军
  - 连刺（方向捅×3）CD6：释放后 0.25s；扇 40° 距 2.2；0.15s 间隔伤 9/9/14；每次自推 0.4；第三下 0.25s 硬直；挥空仍进 CD
  - 盾冲（推过去）CD10：释放后 0.35s；冲刺 4.5 格约 0.35s；碰敌沿冲刺向初速 12 + 伤 12 + 己 0.25s 撞窗；己留 70% 剩余速；撞墙提前结束
  - 蓄势（急停蓄弹）CD12：即放；2.6s 摩擦×10（期间不拉保底）；结束按朝向 11 速弹出 + 0.25s 撞窗
- 取消：右键 / Esc / 瞄准中的取消键。取消不生效。触屏点地只纠偏。
- 磁环（左下角下拉或 GM `H` 换成红方，或打蓝1）：`1`辉环 / `2`斥波 / `3`壁行 / `4`囚环
  - 辉环（磁场）CD11：即放；身周半径 2 留 5s，敌每秒 6，己免
  - 斥波（推波）CD9：即放；锥 70° 射程 4，击退初速约 9，伤 8
  - 壁行（粘壁）CD14：即放；4s 撞墙不反弹沿壁滑，结束按朝向 8 速弹出（位移技）
  - 囚环（困圈）CD12：释放后 0.35s；自身为心或点地（距己≤4），半径 2.5 持续 3.8s；圈内敌物理关死出不去（夹在边缘），仍禁位移技，强放进 2s 短 CD；无 DoT；友军不受困；圈外可滑进
- 链生（左下角下拉或 GM `H` 换成红方）：`1`愈链 / `2`盾脉 / `3`援勾 / `4`扰锋
  - 愈链（治疗链）CD10：释放后 0.3s；扇 40° 距 6；己+最近友 HOT 每秒 6 共 4s（无友仍愈己）
  - 盾脉（护盾脉冲）CD12：即放；最近友≤5（无则仅己）；3.2s 碰撞伤×0.45
  - 援勾（勾友）CD8：即放；距≤8 最近友；拉自己向友，或残血友(<40%)轻拉向己 2 格；不算对敌主动撞（位移技）
  - 扰锋（范围沉默）CD15：释放后 0.2s；身周半径 5；圈内敌沉默 3s 不能放技能（可滑/可撞）；打断短瞄准；友军不受影响
- 钉壳（左下角下拉或 GM `H` 换成红方）：`1`甲垒 / `2`刺盾 / `3`顶冲 / `4`钉锚
  - 甲垒（叠甲）CD10：即放；3.5s 碰撞伤×0.4；未破甲结束回 8
  - 刺盾（反击刺）CD9：被动被主动撞后 2.5s 反 12 + 小推；主动开则 3s 内首次被撞反 16
  - 顶冲（短冲顶）CD8：即放；冲 3 格，命中主动撞+10（位移技）
  - 钉锚（定锚）CD13：释放后 0.3s；扇 45° 距 5；目标速度归零 0.6s，不能改朝向/放技能，仍可被推，位移≥1 断钉；上钉 6；钉中友军主动撞额外 10
- 闪弧（左下角下拉或 GM `H` 换成红方）：`1`侧闪 / `2`掠刃 / `3`回印 / `4`虚影
  - 侧闪（侧移闪）CD7：释放后 0.15s；按瞄选左/右 90°，横向移 2 格（位移技）
  - 掠刃（擦伤刃）CD9：即放；开 4s 窗，相对速度达标且擦肩夹角 60–120° 伤 11；同目标 1s 最多 1 次
  - 回印（标记回响）CD11：释放后 0.25s；距≤5 上标记 6s；下一次主动撞或擦伤额外 14
  - 虚影（虚晃）CD14：即放；2.4s 无碰撞（位移技）；结束速度≥6 则开 0.2s 主动撞窗；困圈内不可用
- 井绳（左下角下拉或 GM `H` 换成红方）：`1`双索 / `2`易位 / `3`索桩 / `4`回索
  - 双索（双钩）CD10：两段瞄——先锁定最近敌≤6，再点落点≤5；释放后 0.4s 自己飞向 B，A 轻拉向连线中点，伤 8，落地速 9（位移技）
  - 易位（换位）CD16：释放后 0.45s；锁敌≤5；交换位置与瞬时速度 50%；伤 5（位移技）
  - 索桩（弹索桩）CD12：释放后 0.3s；投桩≤6 存在 7s；撞桩按壁反弹；己方撞桩开 0.25s 撞窗；同时仅 1 桩
  - 回索（收索）CD9：需有桩；桩与己连线宽 1，线上敌轻拉向中点并降速一档；伤 6；软控
- `R` 只重开一局，不绑 Skill4；设置 → 常规也可重开。正式可用。

蓝方简 bot：蓝1 磁环（推波 / 困圈 / 磁场 / 近壁粘壁）；蓝2 钩刺（保底冲靠近 + 蓄势 + 偶发钩矛，不打连刺）。可被撞死并回场。

调试（设置 → GM，默认开；关则下列键无效，`R` 仍可用。`Z`/`X`/`C`/`V` 双方均在场才生效，不重置一局）：
- `Z`：背后对撞测试（后乘区 ×1.35）
- `X`：侧面撞击测试（侧 ×0.7）
- `C`：正面/对撞测试（前 ×1.0）
- `V`：轻蹭测试（不掉血只改向）
- `R`：重开一局
- `F` 红 +10 分、`G` 蓝 +10 分、`T` 跳过 30s、`Y` 当前阶段剩 1s、`H` 红方循环钩刺 → 磁环 → 链生 → 钉壳 → 闪弧 → 井绳（左下角下拉选中值会跟着变）
- GM 页也可点按钮：碰撞测 / ±分 / 跳时 / 立即回场 / 换英雄

骑士带惯性、摩擦后回到保底 2.5，撞墙/矮柱反弹，速度上限 8。碰撞仍按圆。

碰撞：相对速度 ≥ 4（主动撞窗内阈值 2.5）才掉血，否则轻蹭只改方向。伤害 = 6 × (相对速度 − 阈值) × 受击朝向系数（前 1.0 / 侧 0.7 / 后 1.35），单次上限 28；仅掉血时沿法线轻弹。无敌或同队碰撞不掉血。
