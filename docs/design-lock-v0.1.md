## 已确认锁点
1. 玩家是惯性滑动弹球，不能自由走位；技能前短瞄准 + 撞后 0.3s 强拧（不再画青色提示圈）；**全员实时同时在场**（非回合制）。
2. 目标 3v3；本机先固定 2v2（玩家控红1 + 简 bot 红2 vs 2 蓝简 bot），不做 3v3 切换。开局与每次 `R`：红2 / 蓝1 / 蓝2 从含镜卫的 7 人池均匀随机（同局可重复）；红1 用玩家上次所选作缺省，无记录时钩刺。对局两种模式（设置常规页「玩法」，`ks.lastModeId`，无记录默认八杀；换玩法立刻重开倒计时）：**八杀**先到 8 杀立即胜，240s 比杀数，平则 30s 加时先超前 1 杀，再平比剩余总血（倒地/离场 0）；助攻不计杀；无随机环境伤害圈（地裂不生成也不伤害）；无领地分、隐藏中圈与左右矮柱。**占点**仍是击破 +15 / 助攻 +5 / 领地 +2/秒，先到 100 或时间到分高者胜，加时只计领地，再平下次击破。击破后 5s 回场 + 2s 无敌。
3. 碰撞：只有攻击方枪尖碰到受击方身体才掉血（单向，双方同时戳中可互伤）；伤害 = 6×相对速度标量、单次 cap 28，不再乘朝向、无相对速度门槛；伤≤0 不当命中。成功掉血后枪尖普攻 1.5s CD，CD 中再戳不掉血、不刷新 CD。身子圆碰圆只做物理分离/弹开。技能直伤独立结算，不受此普攻 CD 限制；掠刃荼毒加在那一次成功枪尖上。
4. 按英雄做，每英雄恰好 4 个固定技能，不能改。同局允许重复英雄。
5. 英雄池 7 人：钩刺 / 磁环 / 链生 / 钉壳 / 闪弧 / 井绳 / 镜卫。同局允许重复选。
6. 控制主抓「钉住」「圈住」：钉壳=定锚(0.6s)；磁环=困圈(3.8s，物理关死出不去，另禁位移技)。硬控≤0.6s（回索定身 2s 为明确例外）；1.5s 内二次硬控减半。

## 试玩红线（其余5英雄；钩刺见其细表）

### 磁环

- 过强：愈链对敌 DoT 叠盾脉吸血蒸发 → HOT/DoT每秒6→4 或治疗链4s→3.5s，或盾脉每秒8→6

- 过弱：勾友救不回残血 → 残血拉距2→3格

### 钉壳
- 过强：定锚后队友必吃击破 → 断钉位移≥1格改为≥0.5格，或钉中额外伤10→7
- 过强：叠甲进领地几乎不掉血 → 碰撞伤×0.4→×0.55
- 过弱：短冲顶贴不上 → 冲距3→3.5 或CD8→7

- 过强：贴背枪尖+荼毒无脑戳 → 荼毒+6→4 或侧闪距6→5
