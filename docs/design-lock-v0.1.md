## 已确认锁点
1. 玩家是惯性滑动弹球，不能自由走位；技能前短瞄准 + 撞后 0.3s 强拧；**全员实时同时在场**（非回合制）。
2. 先做 3v3；胜负：击破分 + 领地控分，约 4 分钟一局；击破后 5s 回场 + 2s 无敌；助攻仅最近 1 人。
3. 碰撞：相对速度≥阈值或主动撞才掉血；轻蹭只改方向；伤害乘受击方朝向系数（前1.0/侧0.7/后1.35）。
4. 按英雄做，每英雄恰好 4 个固定技能，不能改。同局允许重复英雄。
5. 英雄池 6 人：钩刺 / 磁环 / 链生 / 钉壳 / 闪弧 / 井绳。
6. 控制主抓「钉住」「圈住」：钉壳=定锚(0.6s)；磁环=困圈(3.8s，物理关死出不去，另禁位移技)。硬控≤0.6s（回索定身 2s 为明确例外）；1.5s 内二次硬控减半。
7. 成长只熟练度/外观，无伤害墙。
8. 沟通：中文；方案先总分 x/10，再评估/建议/方案；决策点用选项卡。不点现实游戏名。
9. 包装名「骑士冲杀」：程序几何骑士（圆盾 + 羽冠 + 矛尖跟瞄准）；Stall 木栏、领地纹章、冲锋残影一并换皮。站点 / 触屏图标用方案 E（红蓝对撞 + 金矛闪光）。碰撞仍是圆，输入/技能逻辑不变。钩刺四技能对外显示：钩矛 / 连刺 / 盾冲 / 蓄势。
10. 磁环已落地（本机）：对内仍是磁场 / 推波 / 粘壁 / 困圈；骑士对外显示辉环 / 斥波 / 壁行 / 囚环。蓝1 简 bot 默认磁环。困圈是物理关死（出不去）但不是硬控：圈内仍可滑、可放非位移技。
11. 链生已落地（本机）：对内仍是治疗链 / 护盾脉冲 / 勾友 / 范围沉默（CHAOS）；骑士对外显示愈链 / 盾脉 / 援勾 / 扰锋。纯治疗 / 护盾不记助攻。
12. 钉壳已落地（本机）：对内仍是叠甲 / 反击刺 / 短冲顶 / 定锚；骑士对外显示甲垒 / 刺盾 / 顶冲 / 钉锚。定锚期间跳过保底拉回，仍可被碰撞推动，位移≥1 格断钉。
13. 闪弧已落地（本机）：对内仍是侧移闪 / 擦伤刃 / 标记回响 / 虚晃；骑士对外显示侧闪 / 掠刃 / 回印 / 虚影。侧移闪 / 虚晃是位移技，困圈内不可用。
14. 井绳已落地（本机）：对内仍是索爆 / 换位 / 弹索桩 / 收索；骑士对外显示索爆 / 易位 / 索桩 / 回索。索爆 CD11：释放后 0.2s，身周半径 2.2 连炸 4 次、间隔 0.35s、每次伤 8，只打敌人；有活跃桩则桩同步炸，4 次后收桩。回索需有桩，桩–己连线宽 1，线上敌伤 6 并定身 2s（速度归零、不能自行离开/放技能，仍可碰撞；超出硬控 0.6s 上限）。左下角下拉可随时指定红方英雄（正式功能，不依赖 GM；只换 kit，血量/位置/对局不变）。GM `H` 仍循环红方钩刺 → 磁环 → 链生 → 钉壳 → 闪弧 → 井绳。索爆单段瞄准，不是位移技，困圈内可用；仅换位是位移技，困圈内不可用。6 人池齐。
15. 战场 UI 锁 Layout B：横屏为主。顶中一颗胶囊：红分 | 计时 | 蓝分（带小队标），不再单独放左上/右上比分胶囊；右下 2×2 紧凑技能（CD 中从 12 点顺时针径向遮罩并显示剩余秒一位小数）、左下英雄下拉、右上小齿轮。战斗飘字只显示数字（伤害 `-12` 红橙、治疗 `+8` 绿、护盾青通道有数值才出），从受击/回血/加盾结算点短上浮后淡出，同帧错开，不挡技能键与顶中胶囊。默认战场不显示 FPS、GM 原文、版本串、坐标网格、碰撞日志等调试层；GM 工具只在齿轮设置里。画布铺满视口并避开 notch。竖持手机只出转横提示，不做竖屏 HUD；PC 窄窗保持横构图并 letterbox。

## 共用数值约定
- 地图长边 20 格，短边 12 格；玩家半径 0.5 格
- 基础移速上限 8 格/秒；保底速 2.5 格/秒（摩擦后低于此值拉回，非完全静止；定锚期间跳过保底拉回）
- 全程弱拧 45°/s；撞后 0.3s 强拧窗 120°/s（替换原约 90°/s 微调）
- 摩擦公式仍按满速→爬行 0.4 的衰减率；实际巡航停在保底 2.5
- 血量 300
- 碰撞阈值 4 格/秒相对速度；主动撞窗口阈值 2.5
- 碰撞伤害 = 6 × (相对速度 − 阈值) × 朝向系数，单次上限 28（先乘再 cap）
- 朝向伤害（相对撞入角相对**受击方**朝向；朝向=速度方向，速度档0用上一帧速度朝向，短瞄准结束刷新）：前 ±45° ×1.0；侧 ±45°～±135° ×0.7；后 ±135°～180° ×1.35
- 轻蹭（相对速度 < 阈值且非主动撞）：只改方向，不乘朝向、不掉血
- 碰撞弹开（仅掉血时）：受击方沿法线轻弹，初速≈2.0×朝向系数×min(1,(相对速度−阈值)/8)；前/侧/后随1.0/0.7/1.35；单次感上限约2.5格当量；轻蹭不弹开
- 主动撞窗口：刚放位移后 0.25s
- 二次硬控：同一目标 1.5s 内再吃硬控，时长与附加伤害减半
- 位移类（吃困圈禁止）= 勾/推/冲/闪/换位/沿壁弹出类主动位移

## 一局规则（最小可玩）
- 约 4 分钟；先到 100 分或时间到分高者胜；平分加时 30s 只比领地分，再平则下次击破方胜
- 击破：对方到 0 血立即离场，击杀方 +15
- 助攻：击杀前 3s 内对死者造成过碰撞伤或技能伤的队友（非击杀者）；多人只认伤害时间最近的 1 人 +5；纯治疗/护盾不算助攻
- 回场：击破后 5s 于己方半场出生点出现；回场 2s 无敌（可滑、可放非伤害控场技；碰撞不伤自己也不造成主动撞伤）
- 领地：圆形中区（圆心地图中心，半径 2.5 格）每秒结算；区内人数严格更多一方 +2/秒；人数相等得 0；击破离场当帧不占人
- 战场：圆角矩形 + 领地纹章圈 + 左右各 1 矮柱；出生己方半场底线
- 开局：红左底 / 蓝右底 Stall 木栏（贴半场底线的描边矩形，开口朝领地、物理四面封死）5s，大号倒计时，栏内不可出；结束围栏消失 → 冲锋 1s（朝领地；前约 0.2s lerp 拉到峰值 7.5，上限仍 8；禁技能、几乎锁拧、全程无敌，并入开局无敌，不另叠；冲锋段不弹出说明板 / toast，帮助只在设置）；随后正常节奏。Esc / 点空白可跳过 Stall，直接进 Playing 并清栏
- 回大厅只结算分与熟练度，家当不砸
- 新手：前 5 局可混机器人；段位 ±1 匹配
- 未开：一人死即负（曾评估，维持积分赛）

1. 钩刺：急停蓄弹→勾过来→捅×3→推过去｜备选勾→捅→急停再推

## 试玩红线（其余5英雄；钩刺见其细表）

规则：过强先拧一项；未触发不改表。

### 磁环
- 过强：困圈内连续击破≥2/局，或领地被困圈控住>8s → 困圈半径2.5→2.2 或持续3.8→3.4s
- 过强：磁场+困圈叠蒸发 → 磁场每秒6→4，或困圈内磁场伤×0.5
- 过弱：困圈命中后无人跟打 → 推波初速9→10 或困圈CD12→10

### 链生
- 过强：队均很少掉到40%以下 → HOT每秒6→4 或治疗链4s→3.5s
- 过强：范围沉默盖住混战让对面整段不能放技能 → 半径5→4 或持续3→2s 或CD15→18s
- 过弱：勾友救不回残血 → 残血拉距2→3格

### 钉壳
- 过强：定锚后队友必吃击破 → 断钉位移≥1格改为≥0.5格，或钉中额外伤10→7
- 过强：叠甲进领地几乎不掉血 → 碰撞伤×0.4→×0.55
- 过弱：短冲顶贴不上 → 冲距3→3.5 或CD8→7

### 闪弧
- 过强：擦伤刃无脑刷 → 擦伤11→8 或同目标间隔1s→1.3s
- 过强：虚晃穿混战零代价 → 结束需速度≥6改为≥7，或CD14→16
- 过弱：标记吃不满 → 额外14→16 或标记持续6→7s

### 井绳
- 过强：换位送残血进火力过多 → CD16→18，或换位后仅目标保留主动撞窗
- 过强：桩+回索控死半场 → 桩持续7→6s、回索宽1→0.75格，或定身2s→1.2s
- 过弱：索爆打不中 → 半径2.2→2.6 或间隔0.35→0.3
