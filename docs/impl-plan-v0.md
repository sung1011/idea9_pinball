## M1 物理约定
- 积分：`x += v * dt`，`dt` 上限 1/20
- 摩擦：`v *= exp(-FRICTION * dt)`，`FRICTION = ln(8/0.4)/2`；M3.5 起低于保底 2.5 拉回，不再归零
- 墙：圆心约束在内缩圆角矩形（角半径 1.0）；完全弹性反弹
- 矮柱：按 2×1 胶囊当墙（半高 0.5 + 球半径）
- 球-球：等质量弹性分离，避免穿模；伤害 / 朝向乘区 / 弹开属 M2
- 速度盖帽 8；调试点击或热键直接给满速 8

## M2 碰撞约定
- 血量 100；相对速度 ≥ 4 才掉血；任一方处于主动撞窗则改用阈值 2.5；否则轻蹭（只做弹性分离/改方向）
- 伤害 = 6 × (相对速度 − 阈值) × 朝向系数，先乘再 cap 28
- 朝向相对受击方：前 ±45° ×1.0；侧 ±45°～±135° ×0.7；后 ±135°～180° ×1.35；速度档 0 用上一帧朝向
- 仅掉血时沿法线轻弹：2.0 × 朝向系数 × min(1,(相对速度−阈值)/8)，感上限 2.5
- 主动撞窗：调试冲刺/给速后 0.25s（M2 不接技能）；M3 技能释放 stub 复用同一窗口
- 本里程碑（M2）不做：击破回场、领地分、Action 层、英雄（已由 M3/M4 补）

## M3 输入约定
- Action：`Aim` / `Skill1–4` / `CancelAim`；FineTune 改为撞后自动强拧；无移动键，点地/鼠标只改 Aim
- 技能：按下进入瞄准（扇形+箭头预览，**无最长时限**），再按同键或左键释放；右键 / Esc / 取消键 取消，不冲量
- 释放：朝向=瞄准方向；**前摇从释放后起算**。M5 起红方固定钩刺，不再用四槽相同 stub
- PC：Aim=鼠标相对红球；Skill1–4=`1`/`2`/`3`/`4`（不绑 `QWE`；`R` 只重开一局）；Cancel=`右键`/`Esc`
- 手机横屏：点地纠偏；右四键=Skill1–4；点技能不抢 Aim；瞄准中显示取消键；禁默认滚动/缩放
- 玩家控红球；蓝球在 M4 改为简 bot；调试 `Z` 背后×1.35 / `X` 侧面×0.7 / `C` 正面×1.0 / `V` 轻蹭（GM 开时）；`R` 只重开一局（正式也可用）

## M3.5 点地手感
- 保底速 2.5；上限仍 8
- 全程弱拧 45°/s；墙/柱/球撞后 0.3s 强拧 120°/s（替换原约 90°/s 微调）
- `targetDir = normalize(pointer − ball)`；只改速度方向，Aim 不加油门
- 无左摇杆；右侧技能四键；点技能不抢 Aim
- Bot 共用保底冲 + 拧向，目标领地或最近敌人
- 不改 M4 计分/回场/领地规则；骑士换皮不做

## M4 一局约定
- 本机：1 人控红方 1 球 vs 蓝方 1～2 个简 bot（`BLUE_BOT_COUNT`，默认 2）
- 状态机：Countdown 5s（各队半场底线 Stall，栏内不可出）→ Playing 240s（先冲锋 2s：朝领地；前 0.4s lerp 拉到峰值 7.5，上限仍 8；禁技能、几乎锁拧、无敌，并入原开局无敌）→ 平分则 Overtime 30s（只计领地）→ 再平则下次击破方胜 → Result
- 开局仪式：Esc 或点空白跳过 Stall，直接进 Playing 并清栏（仍走 2s 冲锋）
- 先到 100 立即结束（须一方严格领先）；到点比总分
- 击破：HP≤0 离场，敌方击杀队伍 +15；击杀前 3s 内对死者造成过碰撞伤的队友（非击杀者）最近 1 人 +5。红方无队友，助攻由 `verifyM4` 双红预留覆盖
- 回场：HP≤0 立即离场（当帧无 hit 也会扫到并进 5s 回场）；己方半场出生；回场 2s 无敌（可滑、可放技能）。开局无敌并入冲锋 2s，不另叠。无敌或同队只做弹性分离
- 领地：圆心地图中心、半径 2.5 格；每秒结算；区内活人数严格更多 +2；相等 0；离场当帧不占人
- 简 bot：无寻路；保底冲靠近 + 急停 + 偶勾；不用方向捅连招；可被撞死并回场
- 调试：齿轮 → GM（默认开）；`Z` 背后×1.35 / `X` 侧面×0.7 / `C` 正面×1.0 / `V` 轻蹭（不重置一局）；`R` 只重开（正式也可用）；`F`/`G` ±分；`T` 跳 30s；`Y` 当前阶段剩 1s；立即回场；`DEBUG_CLOCK_SCALE` 默认可加速时钟。GM 关则调试键无效，`R` 仍可用
- 本里程碑不做：其余英雄、匹配、骑士换皮、联网、满编 3v3 假人 AI

## 验收

- M2：前/侧/后伤害与弹开可辨（调试键 C/Z/X/V）；HUD 显示双方 HP；轻蹭不掉血；调试给速后 0.25s 主动撞窗
- M3：右侧四键 / 1–4 可同键瞄放（不绑 QWE）
- M5：钩刺急停→勾→捅→推可打出；0 血离场 5s 回场有血可动
- M3.5：红球保底巡航约 2.5；金矛尖跟鼠标/点地；弱拧慢转、撞后短时更跟手；技能键不扯 Aim；蓝 bot 冲领地或贴脸

## M4 自测
- `npx tsc --noEmit` 与 `npx vite build` 通过；启动时 `verifyM2` + `verifyM3` + `verifyM4`
- 开局 Stall 5s（红左底 / 蓝右底）后冲锋 2s 无敌，前 0.4s 拉到 7.5，互撞不掉血；围栏消失后才出栏。Esc / 点空白可跳过 Stall
- 撞死蓝 bot：红 +15，HUD 击破提示，蓝回场倒计时 5s，回场后再无敌 2s
- 站领地且人数更多：每秒 +2，圈色随归属变；HUD / 圈标签文案为「领地」
- 调试：`F` 红加到 100 立即结束并弹出结算（击破分 / 领地分 / 用时）；`G` 把双方刷平后 `T`/`Y` 进加时；加时再平后下次击破定胜负
- 结算「再来一局」与 `R` 同重开；可关面板继续看场
- 右上角 `?` 开说明卡；再点 `?`、点空白或关闭钮收起。齿轮开设置（常规 / 版本 / GM），与 `?` 分开
- `R` 与常规页「重开本局」正式可用；GM 默认开，关则调试键无效
- 击破→5s 倒计时→回场满血 + 2s 无敌 + 保底可动；0 血无当帧 hit 也会离场

## M5 约定
- 红方固定钩刺四技能，替换通用 stub。蓝 bot 同英雄、简化 AI（保底冲靠近 + 急停 + 偶勾）
- 瞄准：按下进瞄可无限持有；**释放后才走前摇**再出效果。输入仍为同键二次释放；左键/点地确认释放与保底冲保留
- 勾过来 8s：释放后 0.4s；扇 50° 距 6；墙挡；中则己速 10 飞向目标 + 勾伤 8 + 抵达开主动撞窗；未中 CD 变 4s；不勾友军
- 方向捅×3 6s：释放后 0.25s；扇 40° 距 2.2；0.15s 间隔 3 段伤 9/9/14；每次自推 0.4；第三下 0.25s 硬直（1.5s 内二次硬控减半）；挥空仍进 CD
- 推过去 10s：释放后 0.35s；冲刺 4.5 格约 0.35s；碰敌强推对方沿冲刺向初速 12 + 伤 12 + 己 0.25s 撞窗；己留 70% 剩余速；撞墙提前结束
- 急停蓄弹 12s：即放；0.6s 摩擦×10（跳过保底拉回）；结束按朝向 11 速弹出 + 0.25s 撞窗
- 技能位移可短暂超过移速上限 8；技能直伤计入击破/助攻；无敌或同队不结算
- 0 血：无论当帧有无 hit 都离场并进 5s 回场，避免停在场上的 0 血球
- 本里程碑不做：骑士换皮、其余英雄、联网、满编连招 AI
