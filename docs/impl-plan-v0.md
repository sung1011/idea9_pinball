## M1 物理约定
- 积分：`x += v * dt`，`dt` 上限 1/20
- 摩擦：`v *= exp(-FRICTION * dt)`，`FRICTION = ln(8/0.4)/2`；M3.5 起低于保底 2.5 拉回，不再归零
- 墙：圆心约束在内缩圆角矩形（角半径 1.0）；完全弹性反弹
- 矮柱：按 2×1 胶囊当墙（半高 0.5 + 球半径）
- 球-球：等质量弹性分离，避免穿模；伤害 / 朝向乘区 / 弹开属 M2
- 速度盖帽 8；调试点击或热键直接给满速 8

## M2 碰撞约定
- 血量 300；相对速度 ≥ 4 才掉血；任一方处于主动撞窗则改用阈值 2.5；否则轻蹭（只做弹性分离/改方向）
- 伤害 = 6 × (相对速度 − 阈值) × 朝向系数，先乘再 cap 28
- 朝向相对受击方：前 ±45° ×1.0；侧 ±45°～±135° ×0.7；后 ±135°～180° ×1.35；速度档 0 用上一帧朝向
- 仅掉血时沿法线轻弹：2.0 × 朝向系数 × min(1,(相对速度−阈值)/8)，感上限 2.5
- 主动撞窗：调试冲刺/给速后 0.25s（M2 不接技能）；M3 技能释放 stub 复用同一窗口
- 本里程碑（M2）不做：击破回场、领地分、Action 层、英雄（已由 M3/M4 补）

## M3 输入约定
- Action：`Aim` / `Skill1–4` / `CancelAim`；FineTune 改为撞后自动强拧；无移动键，点地/鼠标只改 Aim
- 技能：按下进入瞄准（扇形+箭头预览，**无最长时限**），再按同键或左键释放；右键 / Esc / 取消键 取消，不冲量
- 释放：朝向=瞄准方向；**前摇从释放后起算**。M5 起红方固定钩刺，不再用四槽相同 stub
- PC：Aim=鼠标相对红球；Skill1–4=`1`/`2`/`3`/`4`（不绑 `QWE`；`R` 只重开一局）；Cancel=`右键`/`Esc`
- 手机横屏：点地纠偏；右下 2×2 四键=Skill1–4；点技能不抢 Aim；瞄准中显示取消键；禁默认滚动/缩放。竖持强制横屏显示。长按技能键约 0.4s 出对外名+一行效果（CD 中也可看）。CD 中从 12 点顺时针径向遮罩并显示剩余秒一位小数；用施放器现有剩余计时，不改 kit 数值
- 玩家控红球；蓝球在 M4 改为简 bot；调试 `Z` 背后×1.35 / `X` 侧面×0.7 / `C` 正面×1.0 / `V` 轻蹭（GM 开时）；`R` 只重开一局（正式也可用）

## M3.5 点地手感
- 保底速 2.5；上限仍 8
- 全程弱拧 45°/s；墙/柱/球撞后 0.3s 强拧 120°/s（替换原约 90°/s 微调）
- `targetDir = normalize(pointer − ball)`；只改速度方向，Aim 不加油门
- 无左摇杆；右侧技能四键；点技能不抢 Aim
- Bot 共用保底冲 + 拧向，目标领地或最近敌人
- 不改 M4 计分/回场/领地规则；骑士换皮已另做（表现层）

## M4 一局约定
- 本机：1 人控红方 1 球 vs 蓝方 1～2 个简 bot（`BLUE_BOT_COUNT`，默认 2）
- 状态机：Countdown 5s（各队半场底线 Stall，栏内不可出）→ Playing 240s（先冲锋 1s：朝领地；前 0.2s lerp 拉到峰值 7.5，上限仍 8；禁技能、几乎锁拧、无敌，并入开局无敌）→ 平分则 Overtime 30s（只计领地）→ 再平则下次击破方胜 → Result
- 开局仪式：Esc 或点空白跳过 Stall，直接进 Playing 并清栏（仍走 1s 冲锋）；冲锋段不弹出说明板 / toast，帮助只在设置
- 先到 100 立即结束（须一方严格领先）；到点比总分
- 击破：HP≤0 离场，敌方击杀队伍 +15；击杀前 3s 内对死者造成过碰撞伤的队友（非击杀者）最近 1 人 +5。红方无队友，助攻由 `verifyM4` 双红预留覆盖
- 回场：HP≤0 立即离场（当帧无 hit 也会扫到并进 5s 回场）；己方半场出生；回场 2s 无敌（可滑、可放技能）。开局无敌并入冲锋 1s，不另叠。无敌或同队只做弹性分离
- 领地：圆心地图中心、半径 2.5 格；每秒结算；区内活人数严格更多 +2；相等 0；离场当帧不占人
- 简 bot：无寻路；保底冲靠近 + 急停 + 偶勾；不用方向捅连招；可被撞死并回场
- 调试：齿轮 → GM（默认开）；`Z` 背后×1.35 / `X` 侧面×0.7 / `C` 正面×1.0 / `V` 轻蹭（不重置一局）；`R` 只重开（正式也可用）；`F`/`G` ±分；`T` 跳 30s；`Y` 当前阶段剩 1s；`H` 红方循环换英雄（左下角下拉也可随时指定，不依赖 GM；只换 kit）；立即回场；`DEBUG_CLOCK_SCALE` 默认可加速时钟。GM 关则调试键无效，`R` 仍可用。默认战场不画调试网格 / FPS / 碰撞日志
- 本里程碑不做：其余英雄、匹配、联网、满编 3v3 假人 AI。骑士换皮已另做（表现层）
